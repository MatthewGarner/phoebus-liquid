# Mocks

Static phone-screen mocks (390×844) from the concept canvas: https://claude.ai/artifact/FosXBnJwPUmf2ZwRqBfTsM
(private to the owner). The "Way more fun" page is the current direction; the
"First pass" page shows the version that was rejected.

The `.dc.html` files are in the canvas's own format and need its runtime to
render, so read them as markup for layout, copy, palette and SVG drawings.
They are references, not specs.
